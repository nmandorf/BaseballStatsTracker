# Login acceptance check

## Preconditions

- The app is running.
- The user has an account.

## Steps

1. Open the app.
2. Fill in the email address.
3. Fill in the password.
4. Select **Log in with email**.
5. Confirm the Home page is visible.

## Expected result

- Login completes without an error.
- Existing teams are visible, or the user can create a team.
