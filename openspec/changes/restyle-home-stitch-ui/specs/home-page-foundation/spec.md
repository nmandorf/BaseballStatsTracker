## ADDED Requirements

### Requirement: Stitch-Informed Home Styling
The home page SHALL present the approved home scope with a Stitch-informed, mobile-first app aesthetic.

#### Scenario: User opens the restyled home page
- **WHEN** a user visits `/`
- **THEN** the first viewport feels like a Baseball Stat Tracker app surface rather than a generic marketing page
- **AND** the interface uses dense, touch-friendly cards, chips, compact controls, and clear mobile hierarchy
- **AND** future tracker areas remain visibly static or planned until later OpenSpec changes approve behavior
